# LEFA Companion

The companion is LEFA's human-facing visual identity.

- [`lefa-companion-root.jpg`](./lefa-companion-root.jpg) — **canonical hand-drawn source**. This owns the companion identity.
- [`lefa-companion-root.svg`](./lefa-companion-root.svg) — animated, GitHub-renderable interface interpretation of that identity.
- `lefa-companion-motion.mp4` — canonical motion reference, still pending ingest.

> **The drawing owns identity. The interface may evolve around it.**

The companion is not a mascot beside a finance dashboard. The companion **is the interface anchor**.
